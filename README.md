# АгроСтрах — FastAPI прототип

## Что делает
- принимает данные полиса, дату события, координаты и 2 URL источников;
- считает NDVI Sentinel-2 для конца июня / начала августа 2025 и 2026;
- маскирует облака/тени/воду/снег;
- запрещает одинаковые URL и одинаковые домены для источников 2/3;
- требует, чтобы один из источников 2/3 был `55.mchs.gov.ru`;
- сервер сам скачивает HTML источников и отправляет только их текст DeepSeek для извлечения фактов;
- DeepSeek НЕ принимает решение о выплате;
- Python возвращает PAY / NO_PAY / NOT_ENOUGH_DATA и журнал состояний.

## Windows PowerShell

```powershell
Заполнить .env по экземпляру .env_example
py -m pip install -r requirements.txt
py -m uvicorn app:app --reload
```
Открыть http://127.0.0.1:8000

## Важно
Текущая автоматическая проверка текстовых источников рассчитана на HTML/текст. PDF возвращается как UNVERIFIED, чтобы программа не выдумывала результат. NDVI — индикатор растительного стресса, не самостоятельное доказательство метеорологической засухи.

## Демонстрационные сценарии

На главной странице есть 4 кнопки демонстрации. Они не вызывают Copernicus/AI API, а воспроизводимо показывают правила контракта:
1. PAY — полис действует и все подтверждения есть.
2. NO_PAY — событие после окончания полиса.
3. NO_PAY — район хозяйства не входит в территорию акта.
4. NOT_ENOUGH_DATA — подтверждён только NDVI, текстовых подтверждений недостаточно.

Прямые URL: `/demo/1`, `/demo/2`, `/demo/3`, `/demo/4`.


## Настройка через .env
Заполните файл `.env` один раз. Проект автоматически загружает его через `python-dotenv`. `TIMEWEB_PROXY_SOURCE` больше не нужен. `TIMEWEB_MODEL` можно оставить пустым — приложение запросит список доступных моделей у агента и выберет первую.
